[Openclaw](https://openclaw.ai/) skill to pull real-time training plans, workouts, fitness metrics (CTL/ATL/TSB), and personal records from [TrainingPeaks](https://trainingpeaks.com/). Uses cookie-based authentication (no API key needed). Use in conjunction with other endurance, cycling, running or swimming triathlon coach skills for best results.
